================================================================================
  ABHI PROJECT MEIN KYA USE HO RAHA HAI (WORKING SETUP)
================================================================================

  MODEL   : gemini-3.1-flash-image
  ENDPOINT: https://aiplatform.googleapis.com/v1/projects/apniapi/locations/
            global/publishers/google/models/gemini-3.1-flash-image:generateContent

  AUTH METHOD: Service Account JSON -> OAuth2 Access Token
    File   : service-account.json (project root)
    Library: google-auth-library (Node.js)
    Scope  : https://www.googleapis.com/auth/cloud-platform

  REQUEST:
    POST <endpoint>
    Authorization: Bearer <access_token>
    Content-Type: application/json
    Body:
    {
      "contents": [{ "role": "user", "parts": [
        { "inlineData": { "mimeType": "image/jpeg", "data": "<base64>" } },
        { "text": "Your prompt here..." }
      ]}],
      "generation_config": { "response_modalities": ["TEXT", "IMAGE"] }
    }

  RESPONSE: data.candidates[0].content.parts
    agar part.inlineData.data hai -> generated image (base64)
    Use: data:image/png;base64,<base64_data>
